# ACTS Method Overview

ACTS treats CT organ segmentation as a sequence refinement problem. Given one annotated reference slice in a 3D CT volume, the method first obtains an initial SAM-based mask sequence, then refines uncertain slices by selecting from a candidate mask pool with a lightweight DQN agent. A SAM mask-decoder adaptation stage can further improve candidate quality.

## Pipeline

1. Reference slice selection

   The reference slice is selected as the slice with the largest target-organ area. Its ground-truth mask is used only to initialize the sequence.

2. Reference seed mask generation

   The reference ground-truth mask is converted into a box prompt and a core positive point. SAM predicts several masks from reference prompts, and a heuristic reference-selection score chooses the seed mask used for propagation.

3. Initial sequence propagation

   Starting from the reference seed mask, SAM prompts are propagated forward and backward along the CT sequence. The output is the initial 3D segmentation.

4. Abnormal slice selection

   ACTS computes sequence inconsistency scores by comparing CT intensity change with mask change. Slices with high inconsistency are selected for candidate generation. An additional foreground-tail detector can select suspicious false-positive tails without using test labels.

5. Candidate pool construction

   For each selected slice, ACTS builds a candidate pool from neighboring masks, interpolated masks, box prompts, point prompts, mask prompts, and non-SAM fallback masks. Details are in [candidate_pool.md](candidate_pool.md).

6. DQN-based correction

   The DQN observes a slice-level state vector and chooses an action corresponding to a candidate type. The selected candidate replaces the current mask only when the environment accepts it.

7. SAM adaptation

   High-confidence DQN-selected masks from training cases are used as pseudo labels to fine-tune only the SAM mask decoder. The image encoder and prompt encoder remain frozen.

8. Rebuild and retrain

   After SAM adaptation, candidate caches are rebuilt with the adapted SAM weights, and a new DQN policy is trained and evaluated.

## DQN State

The DQN state vector contains four groups of features:

- Slice position features: normalized slice index, distance to the reference slice, propagation direction, and normalized step id.
- Current-mask features: area, area ratio to reference, Dice to previous/next masks, area changes, centroid shift, connected-component count, and empty-mask flag.
- CT image features: histogram difference to neighboring slices, inside-mask intensity, surrounding-ring intensity, intensity contrast, and boundary gradient.
- Candidate-pool features: number of candidates, current no-GT score, best candidate no-GT score, empty-mask score, best SAM/non-SAM candidate scores, and SAM score statistics.

The state also includes a one-hot sequence state: `stable`, `expanding`, `shrinking`, `disappearing`, `drift`, or `unreliable`.

## DQN Actions

The action space is discrete:

| Action | Meaning |
|---|---|
| `KEEP_CURRENT` | Keep the current mask. |
| `EMPTY_MASK` | Replace the slice with an empty mask. |
| `STOP_DIRECTION` | Stop correction for the current direction/slice. |
| `SELECT_TIGHT_BOX` | Select the best candidate generated by a tight box prompt. |
| `SELECT_EXPAND_BOX` | Select the best candidate generated by an expanded box prompt. |
| `SELECT_SHRINK_BOX` | Select the best candidate generated by a shrunk box prompt. |
| `SELECT_SHIFTED_BOX` | Select the best candidate generated by a shifted box prompt. |
| `SELECT_PREV_MASK_PROMPT` | Select the best plain mask-prompt candidate. |
| `SELECT_ERODED_MASK_PROMPT` | Select the best eroded mask-prompt candidate. |
| `SELECT_DILATED_MASK_PROMPT` | Select the best dilated mask-prompt candidate. |
| `SELECT_INTERPOLATED_MASK_PROMPT` | Select the best interpolated-mask candidate. |
| `SELECT_POSITIVE_POINT` | Select the best candidate generated by a positive missing-region point. |
| `SELECT_NEGATIVE_POINT` | Select the best candidate generated by a negative false-positive point. |
| `SELECT_BEST_SAM` | Select the best no-GT-scored SAM candidate. |
| `SELECT_BEST_NON_SAM` | Select the best no-GT-scored non-SAM candidate. |

Each action maps to the best cached candidate of that type according to the state-aware no-GT score.

## Reward

The training environment uses the ground-truth mask only to compute reward during training. The reward combines:

- Dice improvement: main term, proportional to the change from current Dice to candidate Dice.
- Existence consistency: rewards correct empty/non-empty decisions and penalizes false empty or false foreground predictions.
- Sequence-local improvement: a small additional term based on Dice improvement.
- Reliability term: rewards non-empty candidates that do not reduce Dice and penalizes invalid empty masks.
- Action cost: small penalty for SAM candidate usage.

During inference, the DQN uses only cached state features and candidate metadata; test ground truth is not used.

## SAM Adaptation

SAM adaptation uses pseudo labels produced by the frozen-SAM DQN pipeline. The adaptation stage:

- Freezes the SAM image encoder.
- Freezes the SAM prompt encoder.
- Trains only the SAM mask decoder.
- Uses DQN-accepted high-confidence pseudo-label slices.
- Supports reward-weighted pseudo-label loss.
- Supports prompt augmentation through box jitter, point sampling, and optional mask prompts.

After adaptation, ACTS rebuilds the candidate pool with the adapted SAM and trains a second DQN policy.
